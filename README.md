# Highland Pine Retreat — homestay booking website

A direct-booking website for a holiday cabin or homestay, so owners can take bookings without paying OTA commission.

**Live:** https://homestay-demo-phi.vercel.app

## Features

- Hero section with a **Check Availability & Book** form
- Amenities, photo gallery and guest reviews
- Fully responsive, single-page and fast to load

## Tech

A single `index.html` with Tailwind CSS (CDN), hosted on Vercel. No build step: open `index.html` in a browser to run it.

## Use it for your property

Change the name, photos, amenities and prices in `index.html`, then deploy to any static host.
